◆ CRM WISE
Seu inbox de WhatsApp e disparos, num app de desktop.

Baixe o CRM WISE

App para Windows — baixe, execute e instale.

⬇️ Baixar para Windows Windows 10/11 · instalador .exe (~100 MB)

Como instalar (1 minuto)

  1. Clique em Baixar para Windows e salve o CRM-WISE-Setup.exe.
  2. Dê duplo-clique no arquivo baixado para instalar (não precisa de administrador).
  3. Se aparecer a tela azul do Windows (SmartScreen): Mais informações → Executar assim mesmo.
  4. Pronto — abra pelo atalho CRM WISE (na área de trabalho e no menu Iniciar).
Para desinstalar: Configurações → Aplicativos (ou Adicionar/Remover Programas) → CRM WISE.

Como entrar

  1. Cadastro: nome, telefone, senha, confirmar senha e a chave de acesso (fornecida pelo administrador).
  2. Login: telefone + senha.
Precisa de uma chave de acesso? Fale com o administrador.
